## ✨ Features
- 🤖 **Play Against the Computer:** The computer makes randomized choices to keep you on your toes.
- 📊 **Score Tracking:** Keeps a live tally of your wins, losses, and ties.
- 🛡️ **Input Validation:** Prevents the game from crashing if you type an invalid move.
- 🔄 **Replayability:** Option to play multiple rounds without restarting the program.

## 🛠️ Tech Stack
- **Language:** HTML5, CSS3, Vanilla JavaScript
- **Libraries:** `random` (for computer choices)
